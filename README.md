# SPDNet: Seasonal-Periodic Decomposition Network for Advanced Residential Demand Forecasting

**SPDNet** is a deep learning framework designed for **residential electricity demand forecasting**.  
It effectively captures intricate **seasonality, periodicity, and sharp fluctuations** in electricity load demand, outperforming traditional and state-of-the-art forecasting models.

## Key Features
✅ **Seasonal-Trend Decomposition Module (STDM)**: Extracts trend, seasonality, and residual components.  
✅ **Periodical Decomposition Module (PDM)**: Uses **Fast Fourier Transform (FFT)** to identify dominant periodic patterns.  
✅ **Hybrid Model Architecture**: Combines **1D CNN, 2D CNN, and Transformer** for accurate forecasting.  
✅ **Handles Multi-Scale Dependencies**: Captures **local, intra-period, and inter-period** dependencies.  
✅ **Robust & Efficient**: Achieves state-of-the-art performance with **lower training time**.
